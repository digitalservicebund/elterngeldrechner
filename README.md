# Elterngeldrechner und Planer

In diesem Repository hat die Entwicklung des Elterngeldrechner im Familineportal des
Bundesministeriums für Bildung, Familie, Senioren, Frauen und Jugend stattgefunden.

Wir haben uns dazu entschloßen die Entwicklung auf gitlab.opencode.de fortzuführen und
dieses Repository zu archivieren. Wir freuen uns über alle Contributions auf Gitlab.

Link zum Elterngeldrechner: https://familienportal.de/familienportal/meta/egr
Link zum neuen Repository: https://gitlab.opencode.de/digitalservicebund/elterngeldrechner
