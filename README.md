# Elterngeldrechner und Planer

In diesem Repository hat die Entwicklung des [Elterngeldrechner](https://familienportal.de/familienportal/meta/egr)
stattgefunden. Der Elterngeldrechner ist weiterhin Teil des Familienportal jedoch haben wir uns dazu entschloßen die
Entwicklung auf [gitlab.opencode.de](https://gitlab.opencode.de/digitalservicebund/elterngeldrechner) fortzuführen
und dieses Repository zu archivieren. Wir freuen uns über alle Contributions auf Gitlab.
